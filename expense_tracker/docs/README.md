# Expense Tracker with Analytics

A Flask-based expense tracker with authentication, CRUD operations, budgets, analytics, DSA utilities, tests, and documentation.

## Features
- User registration/login/logout
- Expense and income management
- Categories and budgets
- Dashboard with charts
- Notifications and reports
- DSA modules: Hash Map, Max Heap, Min Heap, Top-K, Merge Sort, Search, Queue
- Analytics: time-series, trends, moving average, anomaly detection, recurring expenses

## Setup
1. Create a virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Run `python run.py`.

## Project Structure
- `expense_tracker/` application package
- `instance/` SQLite database
- `tests/` pytest suite
- `docs/` project documentation

## Testing
Run `pytest` from the project root.
