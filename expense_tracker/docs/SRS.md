# Software Requirements Specification

## Overview
The Expense Tracker with Analytics project is a Python Flask web application for managing personal finances.

## Functional Requirements
- Authentication and user accounts
- Expense and income CRUD
- Categories, budgets, notifications
- Dashboard analytics
- Reports and CSV export
- DSA modules and analytics utilities

## Non-Functional Requirements
- Secure password hashing
- SQLite persistence
- Responsive web UI
- Automated tests
